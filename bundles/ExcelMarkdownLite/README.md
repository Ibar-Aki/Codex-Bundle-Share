## 復元

Reversible-Script-BundlerのRestore機能で、新しいフォルダーへ復元してください。

本体版は、復元先の tools/Restore-OfficeBinaryPayloads.ps1 をWindows PowerShell 5.1で実行すると、Officeファイル3件と空の .gitkeep をSHA-256検証付きで復元します。コミット済み92ファイル一式が揃います。詳細は同梱の BUNDLE_RESTORE.md を参照してください。

初心者版は最初に README.md を開いてください。ExcelからMarkdownへを作る.bat からショートカットを作成できます。マクロ版Excelは任意で、マクロ版Excelを作る.bat から復元できます。Windows版ExcelとWindows PowerShell 5.1が必要です。古いショートカットは旧フォルダーを参照するため、既存のショートカットを別名へ変更してから、今回の復元先で初回手順を実行してください。起動画面の版番号が1.1.0であることを確認します。

部分的な文字装飾はセル単位の書式へ近似し、該当する場合は警告します。元Excelは上書きしません。

診断情報には版番号・工程・終了コード・エラーや警告のコードを含め、セル内容・ファイル名・シート名・フォルダー名・エラー本文を含めません。経過時間の更新はExcel内部の処理進行を保証する表示ではありません。
