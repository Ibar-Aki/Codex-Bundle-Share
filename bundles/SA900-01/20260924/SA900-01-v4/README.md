## ZIP・bundleからの確認

ZIPはこのフォルダー、完成Excel、テキストbundleを含みます。展開後はこのREADMEからExcelを開けます。

テキストbundleだけを受け取った場合、Officeバイナリは通常のbundle項目からは除外されます。この一式では`payload/WorkbookPayload.json`にExcelの全バイトをBase64で収録しました。Reversible-Script-Bundlerでbundleを展開した後、展開先の`SA900-01-v4`フォルダーで次を実行すると、同じSHAのExcelを`workbook/`へ復元できます。異なる既存Excelは上書きしません。

```powershell
python -X utf8 tools/restore_workbook.py
python -X utf8 tools/check_package.py
```

完成Excelが同梱されたZIPを利用する場合は復元処理は不要です。`check_package.py`はファイルのSHA、Excelコンテナー、帳票シート構成、資料リンクと保存済み検証記録を照合します。Excelの再計算やiPhone試験は実行しません。
